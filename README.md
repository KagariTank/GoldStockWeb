# 项目指标看板

A 股 / 港股 / ETF 多标的同时监控面板，集成黄金分割买点测算、ADR(20) 波动系数、阶梯止盈、保本止损、封单分析、股息率监控、板块资金流向、大盘量能监控等完整看盘工具链。

采用 Vite + Vue 3 架构，ECharts 可视化，数据存浏览器 LocalStorage，无需后端。外观伪装为普通项目看板，上班友好。

---

## 一、快速开始

### 本地开发（推荐）
```bash
pnpm install
pnpm dev      # 启动开发服务器（含 API 代理）
pnpm build    # 构建生产版本
pnpm preview  # 预览生产版本
```

### 首次使用
1. 输入框输入代码（批量用空格/逗号分隔），点「查询并追加」
   - A 股（自动识别上/深）：`600519`、`000001`、`sz300750`
   - 港股（自动识别）：`700`、`00700`、`hk9988`
   - ETF：`510300`、`510500`、`159915`
   - 北交所：`bj830799`
2. 每行右侧点「参数」→ 填入标成本、入标日期、权重数量、阶段峰值/谷值、波动系数 → 保存应用
3. 工具栏点「30s自动刷新」，首次会请求通知权限 + 激活语音

## 三、功能模块

### 3.1 指标监控

多标的实时行情监控，含黄金分割买点、ADR 波动系数、阶梯止盈/保本止损、封单分析、加仓管理。

**主界面列说明：**

| 列名 | 含义 |
|---|---|
| 项目 / 编号 | 证券名称 + 代码，前缀标签 A=沪 B=深 C=港 D=北 |
| 当前值 / 波动 | 现价 + 涨跌额/涨跌幅（触达止盈/止损闪框） |
| 均线 | 今日分时均价（只读） |
| 盘口/封单 | 涨停/跌停时显示封单金额、占比、趋势；非涨停跌停显示买卖一档 |
| 止盈止损 | 移动止盈线 / 动态止损线（触发时数值闪） |
| 距离(%) | 距止盈/距止损的百分比 |
| 黄金分割线 | L1=0.382 常规买点 / L2=0.618 强支撑 / L3=0.786 黄金坑 |
| 8848线 | 警戒高位 = 均价 / 0.98848（日内压力）/ 警戒低位 = 均价 × 0.98848（日内支撑） |
| 操作 | 加仓 / 参数 / 移除 |

**行展开**：点左侧箭头展开底仓详情 + 所有加仓记录的独立止盈止损/盈亏。

**「参数」弹框配置项：**

| 字段 | 含义 | 说明 |
|---|---|---|
| 阶段峰值 | 区间最高价，计算 L1/L2/L3 | 新增标的自动取当日最高 |
| 阶段谷值 | 区间最低价 | 新增标的自动取当日最低 |
| 波动系数(20) | ADR(20)：锁定买入日期窗口下最近 20 根 K 线平均振幅 | 手动填写后刷新不覆盖 |
| 入标日期 | 买入日，锁定 ADR 统计窗口 | 切换日期自动重算 ADR |
| 入标成本 | 买入价，计算止盈/止损/收益 | 手填 |
| 权重（数量） | 持仓股数，显示总盈亏金额 | 手填 |

**「加仓」弹框**：每笔加仓独立计算止盈止损，支持多笔加仓叠加管理。

### 3.2 红利股息监控

追踪高股息标的，自动计算各股息率对应的目标价格。

- 输入股票代码 → 查询追加 → 填写每 10 股股息 → 自动算出股息率 + 4%/4.5%/5%/5.5%/6% 对应价格
- 按股息率降序排列，股息率越高排越前
- 达到阈值时对应价格高亮闪烁 + 语音/通知告警
- 60s 自动刷新价格

### 3.3 板块资金流向

监控 A 股行业/概念板块的主力资金净流入，ECharts 可视化 + 多层告警。

- **板块切换**：行业 / 概念 一键切换
- **柱状图**：流入前 5 + 流出前 5 板块主力净流入对比
- **蜡烛图**：流入前 5 + 流出前 5 板块日内 K 线（累计资金 OHLC），跨日自动重置，localStorage 持久化
- **数据表格**：板块名称、涨跌幅、主力净流入、主力净占比、超大单/大单净流入、领涨股，支持列排序
- **汇总信息**：板块总数、主力净流入合计、流入/流出板块数
- **告警**（5 分钟冷却去重）：
  - 巨量流入（>30 亿）/ 巨量流出（>30 亿）
  - 流向反转（>10 亿流入转 >10 亿流出，或反向）
  - 新晋流入/流出前三

### 3.4 量能监控

监控 A 股大盘成交量对比昨日同期，判断放量/缩量趋势，叠加上证指数分时线。

- **汇总面板**：当日成交额、昨日成交额、今日为昨日同期比率、预测全天成交额
- **趋势状态**：极端放量 / 放量 / 平稳 / 缩量 / 极端缩量，附百分比
- **成交量对比图**（ECharts 折线）：今日累计 vs 昨日累计，分钟级粒度
- **成交额变动图**（ECharts 柱状 + 双轴）：成交额变动柱 + 上证指数加权线（蓝）/ 未加权线（黄）分时叠加
- **分钟数据表**：逐分钟今日/昨日成交量、同比、趋势标记
- **动态刷新频率**：交易时段 15s，非交易时段 60s，自动切换
- **告警**（1 分钟冷却去重）：
  - 趋势转换：缩量转放量 / 放量转缩量
  - 极端比率：极端放量（>200%）、显著放量（>150%）、极端缩量（<50%）、显著缩量（<70%）
  - 加速/减弱：放量加速、缩量加速、放量减弱、缩量减弱
  - 温和放量/缩量
  - 上证加权线上穿/下穿未加权线

## 五、交易策略

### 5.1 黄金分割回撤买点
```
波动区间 = 阶段峰值 - 阶段谷值

L1 常规买点 = 高点 − 0.382 × 区间
L2 强支撑   = 高点 − 0.618 × 区间
L3 黄金坑   = 高点 − 0.786 × 区间
```

### 5.2 日内压力 / 支撑线（8848 线）
```
K = 0.98848 ≈ 1 − φ/10（φ 黄金比例近似）
警戒高位 = 均价 / K
警戒低位 = 均价 × K
```

### 5.3 阶梯移动止盈 + 保本止损

前提：已填入标成本 `buy` 和波动系数 `adr`

```
① 入场时：
   首目标止盈 = buy + 2 × ADR
   初始止损底 = buy − 2 × ADR

② 股价历史高点 ≥ buy + 1.5×ADR（保本里程碑）：
   ⇒ 止损线抬高到 buy，不亏本金

③ 股价历史高点 ≥ buy + 2×ADR（越过首目标）：
   ⇒ 进入移动止盈模式：
      止盈线 = max(首目标, 历史最高 − 1×ADR)
   ⇒ 止损线守住 buy 不动，只上不下
```

两个阈值均用历史高水位 `maxSinceBuy` 触发，涨上去过就算，回落时两条线不回退。

### 5.4 封单分析

涨停/跌停时自动分析封单强度：
- **封单金额** = 封单量 × 100 × 封单价
- **封单占比** = 封单金额 / 流通市值
- **安全等级**：按流通市值分档（<30 亿 / 30~100 亿 / 100~300 亿 / 300~1000 亿 / >1000 亿），不同档位不同安全/危险阈值
- **趋势判定**：对比 5 分钟前封单金额，判定增强/稳定/减弱/骤减
- **四档输出**：安全 / 注意 / 警惕 / 高危（随时炸板），高危触发告警

### 5.5 加仓独立计算

每笔加仓独立维护止盈止损线，与底仓互不干扰，各自跟踪历史高水位，各自触发告警。

## 六、告警机制

### 6.1 指标监控告警

每次刷新后逐行检测，高到低优先级互斥：

| 级别 | 触发条件 | 通知标题 | 语音内容 |
|---|---|---|---|
| P1 紧急 | 现价 ≤ 止损线 | ⚠️ 破位警告 | "破位警告。XXX 已跌破止损 X.XXX" |
| P2 达标 | 现价 ≥ 止盈线 | ✅ 达标提醒 | "达标提醒。XXX 已达止盈 X.XXX" |
| P2 警戒 | 现价跌破 L3 黄金坑 | 🔻 L3 警戒 | "L3 警戒。XXX 跌破 L3 X.XXX" |
| P3 提示 | 上穿 8848 高位 | 📈 触顶提醒 | "触顶提醒。XXX 上穿高位 X.XXX" |
| P3 提示 | 下穿 8848 低位 | 📉 触底提醒 | "触底提醒。XXX 下穿低位 X.XXX" |
| P3 提示 | 跌破 L2 且未破 L3 | 🟠 L2 预警 | "L2 预警。XXX 跌破 L2 X.XXX" |
| P2 高危 | 封单骤减/占比低于危险阈值 | 🔴 封单高危 | "XXX 高危，随时炸板" |
| P2 达标 | 加仓达止盈 | ✅ 加仓达标 | "XXX 加仓N已达止盈" |
| P1 紧急 | 加仓破止损 | ⚠️ 加仓破位 | "XXX 加仓N已跌破止损" |

### 6.2 股息告警

股息率突破 4.5% / 5% / 5.5% / 6% 阈值时触发，只对达到的最高阈值告警（避免重复轰炸）。

### 6.3 板块资金告警

巨量流入/流出、流向反转、新晋前三，5 分钟冷却去重。

### 6.4 量能告警

趋势转换、极端比率、加速/减弱、加权线交叉，1 分钟冷却去重。

### 6.5 告警去重

- 指标监控：内存对象 `alertFlags` 记录首次踩入，价格回到安全区自动清除 flag，下次再踩线才重新提醒
- 板块/量能：基于时间戳的冷却机制，同类型告警在冷却期内不重复

### 6.6 语音合成

基于浏览器 `SpeechSynthesis` API，无需音频文件：
- 自动筛选中文语音包（优先美嘉/婷婷/Google 普通话）
- 自动过滤 emoji，语速 1.0×
- 队列播放 + 超时保护（8 秒强制结束 + 15 秒 busy 卡死重置）
- 不支持的环境回退到 WebAudio 蜂鸣（1 声轻警 / 2 声达标 / 4 声紧急）

## 十一、常见问题

**Q：波动系数(20) 一直是 0？**
A：历史 K 线接口被频控。在「参数」弹框手动填写即可（最近 20 日每日最高价-最低价之和 ÷ 20）。填好后刷新不覆盖。

**Q：浏览器通知不弹？**
A：地址栏左侧权限图标 → 通知设为允许；需以 `http://localhost` 打开（`file://` 模式浏览器会禁用通知）。

**Q：没声音？**
A：浏览器要求用户交互后才能出声。先手动点过任意按钮，再触发告警就有声音。点「测试语音提醒」可验证。

**Q：file:// 模式打不开？**
A：用 `pnpm dev` 或 Live Server 以 `http://localhost` 打开。如需迁移数据，先用「导出」复制 JSON，切到 localhost 后「导入」。

**Q：上班伪装性？**
A：标题栏「项目指标看板」，列名用项目/区间/分级阈值，市场标签是 A 类/B 类/C 类，涨跌颜色蓝-灰-橙非经典红绿，编辑操作藏在「参数」弹框里，列表纯只读。
