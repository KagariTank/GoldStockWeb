# 项目指标看板（黄金分割 + ADR 交易监控面板）

**外观伪装为普通项目看板**，上班友好。底层是 A 股 / 港股 / ETF 多标的同时监控面板，集成黄金分割买点测算、ADR(20) 波动系数、阶梯止盈、保本止损、四层语音告警等完整看盘工具链。

单文件 HTML，双击即开，数据存浏览器 LocalStorage，无需后端。

---

## 一、快速开始

```
直接双击打开 gold.html
推荐用 Chrome / Edge / Firefox，Safari 也可。
```

**首次使用三件事：**
1. 输入框输入代码（批量用空格/逗号分隔），点「查询并追加」
   ```
   A 股（自动识别上/深）：600519、000001、sz300750
   港股（自动识别）：700、00700、hk9988
   ETF：510300、510500、159915
   北交所：bj830799
   ```
2. 每行右侧点「参数」→ 填 **入标成本、入标日期、权重数量、阶段峰值/谷值、波动系数** → 保存应用
3. 工具栏点 **「开启30s自动刷新」**，第一次会请求通知权限 + 激活声音；旁边「测试提醒」可立刻验证语音是否正常。

## 三、「参数」弹框配置项

每行右侧「参数」打开，里面每一项修改后需点「保存应用」才会重算所有阈值（切换入标日期会自动清空波动系数，用新的历史窗口重新锁定计算）。

| 弹框字段 | 含义 | 自动填？ |
|---|---|---|
| 阶段峰值 | 区间最高价，用来算 0.382/0.618/0.786 三个分级阈值 | 新增标的时自动取当日最高价，可手调 |
| 阶段谷值 | 区间最低价，同上 | 新增标的时自动取当日最低价，可手调 |
| 波动系数(20) | **ADR(20)**：锁定买入日期窗口下最近 20 根 K 线平均振幅 (High-Low) | 尝试东财历史K线接口自动拉；被封或失败保持 0 手填；**填过的值刷新不覆盖** |
| 入标日期 | 买入日，用来锁定 ADR(20) 统计窗口（取买入日前 20 根K线，而不是最新20日） | 需要手动选，空着就按最新 20 日 |
| 入标成本 | 买入价，用来算止盈线、保本止损、收益 | 手填 |
| 权重（数量） | 持仓股数，收益列显示总盈亏金额（不填显示每股盈亏） | 手填 |

## 四、交易策略

### 4.1 分级阈值（黄金分割回撤买点）
```
波动区间 = 阶段峰值 - 阶段谷值

L1 常规买点 = 高点 − 0.382 × 区间    （轻度回撤）
L2 强支撑   = 高点 − 0.618 × 区间    （经典 618）
L3 黄金坑   = 高点 − 0.786 × 区间    （深度回撤，高赔率）
```

### 4.2 日内压力 / 支撑线
```
K = 0.98848  ≈ 1 - φ/10（φ黄金比例近似）
警戒高位 = 均价 / K
警戒低位 = 均价 × K
```
均价为交易所接口实时分时均价。

### 4.3 阶梯移动止盈 + 保本止损

前提：已填入标成本 `buy` 和 波动系数(20) `adr`

**里程碑 → 动作映射：**

```
① 入场时：
   首目标止盈  = buy + 2 × ADR
   初始止损底  = buy − 1.5 × ADR

② 股价历史高点 ≥ buy + 1.5×ADR（保本里程碑）：
   ⇒ 止损线立即抬高到 buy，不亏本金
   ⇒ 之后任何时候回踩 buy 就离场；止盈线仍然按首目标不变

③ 股价历史高点 ≥ buy + 2×ADR（越过首目标）：
   ⇒ 进入移动止盈模式，阶梯抬升：
      止盈线 = max( 首目标, 历史最高 − 1×ADR )
   ⇒ 止损线仍守住 buy 不动，只上不下
```

关键：两个阈值都用 **历史高水位 `maxSinceBuy`** 触发，不是只用当前价。涨上去过就算，回落时两条线不回退。

## 五、告警机制（四层 + 语音）

### 5.1 告警级别总览
每次刷新（手动点或 30s 自动）后逐行检测，**从高到低优先级互斥**（破了止损就不会再响 L2）。

| 级别 | 触发条件 | 浏览器通知标题 | 语音朗读内容 | 音效 | 闪烁效果 |
|---|---|---|---|---|---|
| P1 紧急 | 现价 ≤ 止损线下限 | ⚠️ 破位警告 | "破位警告。XXX 已跌破下限 X.XXX（当前 X.XXX）" | 快速中文语音（失败回退 4 连蜂鸣）| 现价橙框 + 下限数值橙闪 + 整行橙底 |
| P2 达标 | 现价 ≥ 止盈线上限 | ✅ 达标提醒 | "达标提醒。XXX 已达上限 X.XXX（当前 X.XXX）" | 语音（失败回退 2 连） | 现价蓝框 + 上限数值蓝闪 + 整行蓝底 |
| P2 警戒 | 现价跌破 L3 黄金坑 | 🔻 L3 警戒 | "L3 警戒。XXX 跌破 L3 阈值 X.XXX（当前 X.XXX）" | 语音（失败回退 2 连） | L3 数值金色闪 + 整行深棕 |
| P3 提示 | 上穿警戒高位 | 📈 触顶提醒 | "触顶提醒。XXX 上穿警戒高位 X.XXX（当前 X.XXX）" | 语音（失败回退单声） | 警戒高数值蓝闪 |
| P3 提示 | 下穿警戒低位 | 📉 触底提醒 | "触底提醒。XXX 下穿警戒低位 X.XXX（当前 X.XXX）" | 语音（失败回退单声） | 警戒低数值红闪 |
| P3 提示 | 跌破 L2 且未破 L3 | 🟠 L2 预警 | "L2 预警。XXX 跌破 L2 阈值 X.XXX（当前 X.XXX）" | 语音（失败回退单声） | L1 / L2 数值橙慢闪 + 整行浅橙 |

### 5.2 去重与重置
- 用内存对象 `alertFlags[code__TYPE]` 记录是否**首次踩入区间**：每个标的 × 每种类型只提醒一次。
- 价格回到安全区间以上，flag 自动 delete，下次再踩线**才会重新提醒**。
- 这样不会每 30 秒刷一次就重复轰炸。

### 5.3 语音合成（无需音频文件）
基于浏览器内置 `SpeechSynthesis` API：
- 系统自带中文语音包朗读告警正文（Win=微软晓晓/云希；macOS=TingTing/亭亭；Android=Google 中文）
- 自动过滤 emoji，不把 ⚠️✅ 当字母念；语速 1.08× 更利落
- 每次告警前 `speechSynthesis.cancel()`，避免多次刷新堆叠
- 不支持的环境自动回退到 WebAudio 合成蜂鸣（1 声轻警 / 2 声达标 / 4 声紧急）

## 八、常见问题

**Q：波动系数(20) 一直是 0？**
A：东财历史 K 线接口被频控了。直接在「参数」弹框手动手填即可（公式：把最近 20 日每日最高价-最低价相加 ÷20）。一旦填好，刷新不会被覆盖。

**Q：选了入标日期后波动系数自动变 0？**
A：这是故意的。买入日变了说明想换一个历史统计窗口（比如当时的 ADR 跟最新 20 日不一样），系统立刻按新日期重新拉 20 根K 线锁定计算。

**Q：浏览器通知不弹？**
A：地址栏左侧有个🔒/小权限图标 → 打开「通知」设为允许；再点一次「开启30s自动刷新」。

**Q：没声音？**
A：浏览器要求**用户交互之后才能出声**。先手动点过「查询并追加」或任意按钮后，再触发告警就有声音。点「测试提醒」按钮是最直接的验证手段。

**Q：上班伪装性够吗？**
A：
- 标题栏是「项目指标看板」，没有股票/牛/金相关字样
- 列名都用项目/区间/分级阈值/基准参数
- 市场标签是 A类/B类/C类，不是 SH/HK
- 涨跌颜色是蓝-灰-橙，不是经典红-绿
- 真正的编辑操作全部藏在「参数」按钮弹框里，列表是纯只读监控
- 不点开弹框别人路过看到就是普通的 KPI 项目监控板
